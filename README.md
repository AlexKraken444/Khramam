# Храмам

Ироничный сайт вымышленной религии на Next.js App Router, React и TypeScript. Багряная палитра, адаптивная верстка, CSS-анимации, поддержка reduced motion и интерактивный ритуал. Фотография находится в `public/vasilissa.jpg`.

## Локальный запуск

```sh
npm ci
npm run dev
```

Открыть http://localhost:3000.

## Проверка

```sh
npm run typecheck
npm run build
node --experimental-strip-types --test tests/blessings.test.mjs
```

## Vercel

Импортировать репозиторий `AlexKraken444/Khramam` в Vercel и нажать Deploy. Framework Preset: Next.js, Root Directory: корень репозитория. Команда сборки: `npm run build`. Переменные окружения не требуются. Использовать Node.js 24.x (или совместимую с Next.js версию).

Шрифты Cormorant Garamond и Manrope загружаются из Google Fonts в браузере; при отсутствии доступа используются Georgia и Arial. Во время сборки загрузка шрифтов не требуется.

Сайт — рофл. Религия вымышленная.

Счётчик благословений персональный и хранится в localStorage этого браузера. Можно получить одно благословение за календарный день по местному времени. Полученное благословение нельзя отменить через интерфейс; повторные нажатия и перезагрузка не увеличивают счётчик. Вкладки синхронизируются, Web Locks сериализует получение в поддерживаемых браузерах. Очистка данных браузера сбрасывает счётчик; синхронизация устройств и серверная защита от обхода не предусмотрены.
